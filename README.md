# 무역놀이 웹앱 v0.3

v0.2 전체 기능에 교사용 로비 관리 기능을 추가한 실행 가능한 전체 배포본입니다.

## v0.3 추가
- 잘못 참가한 모둠 내보내기
- 내보낸 iPad 참가 ID 초기화 후 재참가
- 모둠별 나라 수동 배정
- 나라 중복 배정 방지
- 무작위 배정 유지
- 참가 마감 / 다시 열기
- 미배정/중복/7모둠 이상 게임 시작 차단

## 배포
GitHub 저장소의 기존 실행 파일을 이 폴더 내용으로 덮어쓰고 main에 Commit하면,
Render Auto-Deploy가 켜진 경우 기존 https://trade-classroom.onrender.com 에 자동 재배포됩니다.

교사용: /teacher.html
학생용: / (교사용 QR로 접속 권장)
건강 확인: /health → version 0.3

교사용 화면의 `🧪 수업 테스트 시작`으로 6개 가상 모둠을 즉시 만들고, PC 한 대에서 각 학생 iPad 화면을 미리볼 수 있습니다. 게임 설명/무역/소비 결과/3R 건설 설명/건설/최종 결과로 바로 이동하는 UI 검토용 프리셋도 제공합니다. 시뮬레이션 방은 실제 수업방과 분리됩니다.
