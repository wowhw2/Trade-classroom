# 무역놀이 웹앱 — 인터넷 배포형 MVP 0.2

초등학교 사회과 '무역의 필요성과 과정' 모둠 활동용 실시간 웹앱입니다.

## 수업 구조
- 교사: PC + 전자칠판
- 학생: 모둠별 iPad 1대
- 교사/학생 네트워크가 달라도 인터넷을 통해 같은 서버에 접속
- 교사가 방을 만들면 QR 코드와 6자리 보조 방 번호 생성
- 학생은 QR → 모둠 이름 입력 → 참가
- 개인정보/학생 계정 없음

## 기본 게임
- 6개 나라: 식량/목재/자동차/석유/섬유/기술력 특화
- 6라운드 기본
- 생산: 교사가 라운드 생산 시작 → 각 나라 특산품 자동 추가
- 무역: 대면 협상 후 전자계약. 자원과 화폐 모두 거래 가능
- 거래 게시판: 직접 협상이 어려운 모둠의 보조 통로
- 소비: 교사가 소비 시작 → 필요자원 자동 제출 → 부족량에 따라 보상 감소
- 재고: 소비 직후 자원 종류별 5개 초과분 자동 폐기
- 건설: 3라운드부터 개방. 생산량 또는 소비보상 증가
- 최종 총자산: 남은 현금 + 시설 건설비 합계

## 현재 1차 밸런스
- 초기자본 20
- 기본 생산량 12
- 기본 소비보상 10
- 부족 1개당 보상 -1
- 자원별 재고상한 5
- 건설 개방 3R
- 시설: 비용 14~22, 효과 +1~+2

`12`를 기본 생산량으로 둔 이유: 학습지의 6개 나라가 각각 라운드당 총 12개 자원을 필요로 하고, 세계 전체에서도 각 자원 종류별 필요량 합계가 12개라서, 완전한 무역이 이루어지면 이론적으로 모두 충족 가능한 기준점입니다. 생산시설은 무역 실패/재고 손실을 완충하는 역할을 합니다.

## 로컬 실행
```bash
npm install
npm start
```
교사: http://localhost:3000/teacher.html

## 인터넷 배포
### Render Blueprint
저장소에 이 폴더를 올린 뒤 Render에서 Blueprint로 `render.yaml`을 사용하면 됩니다.
배포된 HTTPS 주소의 `/teacher.html`을 교사가 사용합니다. QR에는 자동으로 배포된 공개 주소가 들어갑니다.

다른 호스팅을 쓸 때는 Node.js 웹서비스로 `npm install` → `npm start`를 실행하면 됩니다. 프록시 환경에서 주소 자동 인식이 어려운 경우 환경변수 `PUBLIC_BASE_URL=https://실제주소`를 설정합니다.

## 중요
현재 방 상태는 서버 메모리에 저장됩니다. 서버가 재시작되면 진행 중인 방이 사라집니다. 한 차시 수업용 MVP로는 단순하고 빠르지만, 정식 운영판에서는 Redis/DB 영속화를 권장합니다.
