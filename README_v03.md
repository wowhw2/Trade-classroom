# Trade Classroom v0.3 patch

이번 패치는 현재 배포된 v0.2에 다음 기능을 추가하기 위한 변경 파일입니다.

1. 교사가 잘못 참가한 모둠을 로비에서 내보내기
2. 내보낸 iPad의 로컬 참가 ID 삭제 → QR로 재참가 가능
3. 나라를 모둠별로 직접 선택
4. 나라 중복 배정 방지
5. 무작위 배정 기능 유지
6. 참가 마감 / 다시 열기
7. 모든 모둠에 나라가 배정되지 않으면 게임 시작 차단

이 ZIP은 안전한 '패치 안내본'입니다. 현재 GitHub의 server.js / public/teacher.js /
public/student.js에 해당 내용을 통합해야 합니다. ChatGPT GitHub 연결이 쓰기 403이라 자동 커밋은
현재 불가능합니다.
